# Радар вакансий

Каждое утро собирает вакансии из открытых источников, приводит их к единому виду,
считает статистику по рынку и в 12:00 присылает подборку в Telegram.

Учебный проект, который делается всерьёз: с тестами данных, автозапуском
и дашбордом. Разбор архитектуры и решений — в `decisions.md`.

## Что здесь лежит

```
vacancy-radar/
├── collectors/            шаг 1 — забрать вакансии из источников
│   ├── arbeitnow.py       первый источник, написан руками
│   └── inspect_data.py    посмотреть глазами, что собралось
├── load/                  шаг 2 — положить собранное в облако
│   └── to_bigquery.py     (заготовка, включим на второй неделе)
├── dbt_radar/             шаг 3 — привести в порядок и посчитать
│   ├── dbt_project.yml
│   └── models/
│       ├── staging/       причёсанные данные
│       └── marts/         витрины для дашборда и бота
├── .github/workflows/     шаг 4 — запуск по расписанию и проверки
├── data/                  сырые файлы (в git не попадают)
├── CLAUDE.md              правила, по которым помощник пишет код
└── decisions.md           мой конспект: что сделала и почему
```

## Как запустить прямо сейчас

Нужен только Python. Ни облака, ни ключей, ни регистраций на этом шаге нет.

```bash
python -m venv .venv
source .venv/bin/activate        # на Windows: .venv\Scripts\activate
pip install -r requirements.txt

python -m collectors.arbeitnow      # собрать вакансии в data/raw_arbeitnow.jsonl
python -m collectors.inspect_data   # посмотреть, что собралось
```

Если во втором скрипте видно вакансии, компании и города — первый шаг сделан.

## План

| Неделя | Что делаем | Что появляется в репозитории |
|---|---|---|
| 1 | сбор данных + облако | коллекторы, таблица в BigQuery |
| 2 | dbt | staging и marts с тестами и документацией |
| 3 | обогащение моделью | стек, грейд, вилка, склейка дублей |
| 4 | витрина и доставка | дашборд Looker Studio, Telegram-бот, автозапуск |
